# Work log: 2026-11-20

**Goal today:** get the dataset onto the Hugging Face Hub in a shape that suits training 4 separate models (one per organelle).

## Outcome in one line
Pairs CSV switched to a wide format, `upload_to_hub.py` written and its HF token wired up through `.env`. The first push got about 50% through the shards and then hit an HF rate limit (429), so **the upload is not finished yet**.

## Timeline
1. **Format decision.** Long format (one row per input-organelle pair) would repeat the input image up to 4 times. Chose **wide**: one row per (study, image_id, input modality), with `<organelle>_file` / `<organelle>_z` columns that are empty when that image has no usable image of the organelle. For one organelle's model, keep rows where its file column is not empty.
2. **`create_pairs.py` changed to wide rows.** Columns: study, image_id, input_modality, input_z, input_file, then `<organelle>_file` and `<organelle>_z` for nucleus, mitochondria, tubulin, actin. z columns are nullable ints; sorted by study, image_id, input modality. Raises on an unknown organelle channel.
3. **`upload_to_hub.py` written, then simplified** at your request (no extra edge-case handling). Reads `input_output_pairs.csv`, keeps only studies whose folder is in `data/`, stores each image as raw `.ome.tiff` bytes in a binary column, empty organelles as None, pushes private.
4. **HF token via `.env`.** Added `python-dotenv` (`uv add`), and `load_dotenv(ROOT / ".env")` with an explicit path (the no-argument form crashed in my test). `HF_TOKEN` in the environment takes priority over the cached `hf auth login` token, which is a different token. `.env` is git-ignored. Token values were never read or printed.
5. **First push.** `REPO` set to `AG2307/light-my-cells`. Auth and dataset build worked; upload failed partway with `429 Too Many Requests` from HF's storage server (`cas-server.xethub.hf.co`). Not a code bug.
6. **Reading it back for training** (explained, not yet run): `load_dataset(REPO, split="train")`, filter rows where the organelle column is not None, decode with `tifffile.imread(io.BytesIO(bytes))`, split train/val by (study, scene_id) so both inputs of a two-input image stay together.

## Things to know
- A 429 before the commit leaves nothing half-written in the repo; shards already sent are stored by content, so a re-run should skip them.
- On Linux or Mac the `.env` key must be `HF_TOKEN`; yours is lowercase `hf_token`, which only works on Windows.
- The script pushes as soon as it is run (no main guard).
